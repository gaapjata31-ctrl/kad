■ 一文一義トレーナー v7

添削82文（18年分＋答練）｜名詞化のコツ｜名詞化練習14問 ── 切る技術と束ねる技術

■ この教材の位置づけ

添削レポートが「詰め込みすぎた文を切る」技術なら、名詞化は「動詞が渋滞した文を束ねる」技術。切る・束ねるの両方を持つと、字数と読みやすさを自在に調整できる。

ルール 1｜動詞は1文に1〜2個まで

私は資格を取得し、知識が身に付き、視野が広がり、業務に活かすことができた。（動詞4個）

資格取得による知識・視野の拡大を、業務に活かすことができた。（動詞1個）

文を書いたらまず動詞を数える。3個以上あれば削れるサイン。

ルール 2｜名詞化の7パターン

1｜〜して → 〜を通じ

勉強会を開催して意識を高めた

勉強会の開催を通じ、意識の向上を図った

2｜〜したことで → 〜により

ツールを導入したことで時間が減った

ツールの導入により、時間削減を実現した

3｜〜し、〜し → 〜・〜（名詞並列）

蓄積し、共有し、継承していく

蓄積・共有・継承

4｜できるようになった → 可能となった

対応できるようになった

対応が可能となった

5｜〜する機会があり → 〜を通じ

会話をする機会があり、知ることができた

会話を通じ、〜を知ることができた

6｜〜だった〜 → 〜な〜（連体修飾）

対応が困難だった事例

困難事例

7｜〜を行うように → 〜体制の構築に

相談を行うように努めた

相談体制の構築に努めた

ルール 3｜2〜3文は1文に統合できることが多い

原因・行動・結果が別々の文になっているときは、接続語でつないで1文にまとめる。

ミスが発生した。私はすぐ連絡しなかった。クレームが拡大した。（3文・6動詞）

ミス発生時の連絡遅れにより、クレームの拡大を招いてしまった。（1文・1動詞）

前の文と意味がつながっているなら、「〜により」「〜ことで」「〜を通じ」でつないで1文にできる。※逆に別の情報なら切る（添削レポートの一文一義）。同じ情報の分断は束ね、別情報の同居は切る。

コツ｜書いたら必ずこの3問に答える

Q1 動詞はいくつある？

→ 3個以上なら削る。主動詞を1つ決めて他を名詞化する。

Q2 「して」「したことで」「することで」がある？

→ 「を通じ」「により」に変換できる。

Q3 前の文と意味がつながっている？

→ 1文に統合できるサイン。接続語でつなぐ。

まず「主動詞（一番言いたい動詞）」を決める。それ以外はすべて名詞化の候補。

追加コツ 1｜接続・圧縮の定型表現

〜を踏まえ（経験・事実を前提として）

このような経験があるので、〜について述べたい

このような経験を踏まえ、〜について述べていきたい

〜を契機に（〜がきっかけで）

この経験があったことで意識が変わり

この経験を契機に意識が変わり

〜に際して（〜するときに）

マニュアルを作成するときに工夫したのは〜

マニュアルを作成するに際して工夫したのは〜

〜に当たって

提案をするときに特に意識したのは〜

提案するに当たって特に意識したのは〜

〜を通じ（手段・過程を経て）

ミーティングを繰り返してチームの信頼を得た

定例ミーティングの実施を通じ、チームの信頼を得ることができた

〜に伴い（変化とともに）

社会が変化したので区民のニーズも複雑になった

社会環境の変化に伴い、区民ニーズも複雑化・多様化している

追加コツ 2｜文末語尾のバリエーション

努力した→〜に努めた／〜に取り組んだ
目標にした→〜を図った／〜を目指した
達成した→〜を実現した／〜を達成した
作り上げた→〜を構築した／〜を整備した
育てた→〜を醸成した／〜を高めた
続けている→〜に努めている／〜に取り組んでいる
これからもやっていく→〜に邁進していく／〜に尽力していく

追加コツ 3｜「私は」を繰り返さない

私は提案した。私は実行した。私は成果を出した。（「私は」3回）

私は〜を提案し実行した。これにより〜という成果を実現した。（「私は」1回）

最初の1文だけ「私は」を置く。その後は「これにより」「この取組により」「これを踏まえ」「その結果」で主語を切り替える。

追加コツ 4｜強調の表現3種

不可欠である（最強の強調）

報連相は業務遂行において不可欠である。

極めて重要である（締めでよく使う）

コンプライアンスの徹底が極めて重要となってくる。

欠かせない（やわらかい強調）

チームワークは組織力の向上に欠かせない。

1つの論文で同じ表現は2回まで。3種をローテーションすると自然に読める。

追加コツ 5｜名詞化の可否判定テスト

動詞に「〜の」か「〜という」を付けて名詞にしてみる。意味が保たれれば名詞化可、ニュアンスが落ちれば動詞のまま残す。

「〜の」テスト｜○ 名詞化できる例

勉強会を開催する／返戻を削減する

勉強会の開催／返戻の削減（意味そのまま → 圧縮候補）

「〜という」テスト｜○ 節ごと名詞化

ミスが多発していた／職員の意識が低い

ミスの多発という状況／意識の低さという課題

✕ ニュアンスが消える例

「報告してしまった」→「報告の実施」だと不本意さが消える。「改善すべきだ」→「改善の必要性」だと主張が弱まる

後悔・反省・判断・主張を表す動詞は、動詞のまま残す。

使い分けの実例

ミスが多発していたので、私は手順書を見直すべきだと考え、提案した。

ミスの多発という状況を受け、私は手順書の見直しを提案した。（前半2つを名詞化し、主動詞「提案した」だけ残す）

追加コツ 6｜名詞化しない・できない動詞

タイプ1｜和語動詞 → 漢語に置き換える

和語はそのまま名詞化できない。対応する漢語を探す。

減らす→削減／知る→把握・認識／もらう→取得／気づく→早期発見

タイプ2｜ニュアンスが消える表現

「〜てしまった」（後悔）／「〜べきだ」（主張）／「〜しなかった」（否定の事実）

反省や判断を示す文では動詞のまま残す。ただし「連絡しなかった→連絡の怠り」のように、あえて解釈に変える使い方は有効（第12問参照）。

タイプ3｜主動詞は名詞化禁止

文には述語が最低1つ必要。すべて名詞化すると文が成立しない。

「なる・ある」等は他の名詞化を受け止める側（「〜が可能となった」）として残ることが多い。

2個残す場合の条件：2つの動詞の間に論理関係（手段→目的、原因→結果）があること。単なる並列の2個なら片方を名詞化する。

追加コツ 7｜字数不足は「密度」で戻す

スリム化で浮いた字数は、動詞句の水増しではなく情報の単位を増やして戻す。優先順に。

1｜判断理由を1文足す（最優先）

「勉強会形式としたのは、一方的な通達では当事者意識が生まれないと考えたためである。」→ 思考プロセスの提示は採点で最も評価される。40〜60字。

2｜結果を「定量＋定性＋波及」の3段に

「返戻が約8割減少した。加えて職員から〜の声が聞かれた。この手法は他係にも展開された。」

3｜主任視点の一文を挟む

「係全体の業務品質」「後進への継承」など、個人の成果を組織の話に引き上げる。2級職の加点要素。

4｜特別区への接続を厚くする

「この経験は、多様な区民ニーズへの対応においても〜」と経験→区政の橋渡しを具体的に。

5｜課題の背景に社会的文脈を1文

「制度が複雑化する中〜」など、なぜその課題が重要かの前提を書く。

書き順：スリムに書き切る → 字数確認 → 上の1・2・3から優先的に補充。短い文をたくさん置く構成なら、一文一義と字数確保は矛盾しない。

追加コツ 8｜書く前に動詞を決める

文は述語（動詞）が核。材料から書き始めると動詞が渋滞する。主動詞を先に確定し、材料を名詞化してぶら下げる。

階層ごとの起点

論文全体 → 構成から（序論・本論・結論）／段落 → 結論の一文から（PREPのP）／文 → 主動詞から（言い切る動詞を1つ確定）

実戦手順｜段落を書く前に主動詞をメモ

例：「提案した／図った／実現した／学んだ」と4つ書き出す

→ 段落4つの骨格が立つ。あとは名詞化した材料を差し込むだけ。語尾の重複チェックも書く前に済む。

動詞を決めると構文も決まる

「図った」→手段を「〜を通じ」でぶら下げる／「実現した」→成果を名詞並列で列挙／「提案した」→何を（名詞化）・なぜ（判断理由）を配置

面接も同じ。言い切る動詞を先に決めてから話し始めると一文が短くなる。「一文を短く。言い切る」＝「動詞を先に決める」。
